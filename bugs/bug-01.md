# BUG-01: POST /api/books буруу JSON биетэй хүсэлтэд 400 биш 200 OK буцаадаг

Орчин:  Уншлагын жагсаалт v2.0, Safari 26.6.2, macOS 26.6.2, 2026-11-21
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном: Тунгалаг Тамир, Clean Code, The Pragmatic Programmer)

## Дахин гаргах алхам
1. Терминал дээр:
   ```
   curl -s -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d 'энэ JSON биш'
   ```
2. Хариуны статусын мөрийг хар.

Хүлээгдэж байсан: `HTTP/1.1 400` алдаа — спецификаци: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана».
Бодит үр дүн:     `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}`. Клиент хүсэлт амжилттай болсон гэж ойлгоно.

Ноцтой байдал: Major — API-г ашиглагч алдаатай хүсэлтээ илрүүлж чадахгүй, буруу өгөгдөл чимээгүй алга болно.
